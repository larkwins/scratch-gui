# Scratch GUI 自动保存功能

## 功能说明

已为 Scratch Web 项目添加了自动保存功能，可以自动将项目保存到浏览器的 localStorage 中。

## 主要特性

### 1. 自动保存
- **触发条件**: 当项目有任何修改时（添加积木、修改角色、更改背景等）
- **保存延迟**: 3秒防抖延迟，避免频繁保存影响性能
- **存储位置**: 浏览器 localStorage（本地存储）
- **保存提示**: 在浏览器控制台显示保存状态

### 2. 自动恢复
- **检测时机**: 页面加载时自动检测是否有自动保存的项目
- **用户选择**: 弹窗询问用户是否恢复，显示保存时间
- **智能判断**: 如果用户选择不恢复，将继续加载默认项目

### 3. 存储管理
- **大小检测**: 自动检测项目大小，超过 8MB 时提示警告
- **空间保护**: 当存储空间不足时，自动处理异常
- **数据清理**: 加载失败时自动清除损坏的数据

## 实现细节

### 文件结构
```
src/
├── lib/
│   └── auto-save-hoc.jsx    # 自动保存 HOC 组件
└── containers/
    └── gui.jsx              # 集成自动保存功能
```

### 核心实现

1. **自动保存 HOC** (`auto-save-hoc.jsx`)
   - 监听 Redux store 中的 `projectChanged` 状态
   - 使用 lodash.debounce 实现防抖
   - 通过 VM 的 `saveProjectSb3()` 方法获取项目数据
   - 将项目转换为 base64 存储到 localStorage

2. **集成到 GUI** (`gui.jsx`)
   - 在 HOC 组合链中添加 `AutoSaveHOC`
   - 自动注入到应用根组件

### 存储键名
- `scratch_autosave_project`: 项目数据（base64 格式）
- `scratch_autosave_time`: 保存时间（ISO 格式）

## 使用说明

### 开发者
功能已自动集成，无需额外配置。

### 用户
1. **正常使用**: 编辑项目时会自动保存，无需手动操作
2. **查看状态**: 打开浏览器控制台可查看保存状态
3. **恢复项目**: 刷新页面或重新打开时，如有自动保存会弹窗提示

### 控制台日志示例
```
✓ 项目已自动保存 (0.52MB)
✓ 已从浏览器缓存恢复项目
✓ 已清除自动保存的项目
```

## 浏览器兼容性

- ✅ Chrome / Edge (推荐)
- ✅ Firefox
- ✅ Safari
- ⚠️ 需要支持 localStorage 和 FileReader API

## 限制说明

1. **存储大小**: localStorage 通常限制 5-10MB
   - 对于大型项目（>8MB），将不会自动保存
   - 建议用户手动下载大型项目

2. **跨浏览器**: 自动保存数据仅在同一浏览器中有效
   - 不同浏览器之间无法共享
   - 隐私模式/无痕模式可能不保存

3. **清除数据**: 清除浏览器数据会删除自动保存
   - 建议重要项目手动下载备份

## 故障排除

### 问题：自动保存不工作
- 检查浏览器是否支持 localStorage
- 查看浏览器控制台是否有错误信息
- 确认存储空间是否充足

### 问题：恢复失败
- 检查控制台错误日志
- 尝试清除浏览器缓存后重试
- 数据可能已损坏，需重新创建项目

### 问题：提示存储空间不足
- 清理浏览器数据和缓存
- 减小项目大小（删除不用的角色和声音）
- 使用手动下载功能保存大项目
