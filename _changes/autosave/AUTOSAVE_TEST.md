# 自动保存功能快速测试指南

## 准备工作

1. 启动开发服务器：
```bash
npm start
```

2. 打开浏览器访问 `http://localhost:8601`

3. 打开浏览器开发者工具（F12）查看控制台

## 测试步骤

### 测试 1: 基本自动保存

1. ✅ 打开 Scratch 编辑器
2. ✅ 在控制台应该看到：`🎨 Scratch 自动保存已启用`
3. ✅ 添加一些积木到工作区
4. ✅ 等待 3 秒后，控制台应显示：`✓ 项目已自动保存 (0.XX MB)`

### 测试 2: 项目恢复

1. ✅ 完成测试 1（确保有自动保存）
2. ✅ 刷新浏览器页面（F5）
3. ✅ 应该弹出确认对话框，显示保存时间
4. ✅ 点击"确定"，项目应该恢复到保存时的状态
5. ✅ 控制台显示：`✓ 已从浏览器缓存恢复项目`

### 测试 3: 拒绝恢复

1. ✅ 完成测试 1（确保有自动保存）
2. ✅ 刷新浏览器页面
3. ✅ 在确认对话框中点击"取消"
4. ✅ 应该加载默认的空白项目

### 测试 4: 控制台工具

在浏览器控制台中测试以下命令：

```javascript
// 1. 查看帮助
ScratchAutoSave.help()

// 2. 检查自动保存
ScratchAutoSave.check()
// 应显示：保存时间和大小

// 3. 查看存储信息
ScratchAutoSave.storageInfo()
// 应显示：localStorage 使用情况

// 4. 导出项目
ScratchAutoSave.export('test-project.sb3')
// 应下载一个 .sb3 文件

// 5. 清除自动保存（慎用）
ScratchAutoSave.clear()
// 应清除自动保存数据
```

### 测试 5: 持续编辑

1. ✅ 进行以下操作，每次等待 3 秒观察控制台：
   - 添加角色
   - 添加背景
   - 添加声音
   - 添加变量
   - 修改代码块
2. ✅ 每次修改后都应该看到自动保存日志

### 测试 6: 大项目警告

1. ✅ 添加大量高清图片作为背景和角色
2. ✅ 当项目超过 8MB 时，控制台应显示警告
3. ✅ 此时将不会自动保存

## 预期行为

### 正常情况
- ✅ 每次修改后 3 秒自动保存
- ✅ 控制台显示保存确认信息
- ✅ 刷新页面能恢复项目
- ✅ 用户可以选择是否恢复

### 边界情况
- ✅ 项目太大（>8MB）时显示警告，不保存
- ✅ 存储空间不足时显示错误
- ✅ 数据损坏时清除并提示用户

## 常见问题排查

### 问题：没有看到自动保存日志
**检查点：**
- [ ] 是否进行了修改？（必须有 projectChanged 事件）
- [ ] 是否等待了 3 秒？（debounce 延迟）
- [ ] 控制台是否有错误？

### 问题：刷新后没有恢复提示
**检查点：**
- [ ] 之前是否成功自动保存？
- [ ] localStorage 是否被清除？
- [ ] 是否在隐私模式下？

### 问题：恢复失败
**检查点：**
- [ ] 控制台错误信息
- [ ] localStorage 数据是否损坏
- [ ] VM 是否正确初始化
